# Setup GitHub Repository

## Quick Start

This folder contains all files ready to upload to GitHub.

## Steps to Upload

### 1. Initialize Git (if not already done)

```bash
cd sp500-github
git init
git add .
git commit -m "Initial commit: S&P 500 Returns Prediction Full Stack Application"
```

### 2. Create Repository on GitHub

1. Go to: https://github.com/new
2. Repository name: `sp500-prediction-fullstack`
3. Description: "Full-stack S&P 500 Returns Prediction with ML API and React Frontend"
4. Choose **Public** or **Private**
5. **DO NOT** initialize with README (we already have one)
6. Click **"Create repository"**

### 3. Push to GitHub

```bash
git remote add origin https://github.com/RisheendraReddy/sp500-prediction-fullstack.git
git branch -M main
git push -u origin main
```
