# Project Outputs

This document describes all outputs generated by the S&P 500 Returns Prediction project.

## 1. Training Output (`train.py`)

When you run `python3 train.py`, the following outputs are generated:

### Console Output
- **Data Loading**: Confirmation of loaded training data (rows, columns)
- **Data Split**: Train/validation split information
- **Feature Count**: Number of features used
- **Training Progress**: Model training status
- **Validation Metrics**: Performance metrics on validation set:
  - **RMSE** (Root Mean Squared Error)
  - **MSE** (Mean Squared Error)
  - **MAE** (Mean Absolute Error)
  - **R²** (R-squared coefficient)
  - **Correlation** (Correlation between predictions and actual values)

### Example Console Output:
```
Loading training data...
Loaded training data: 10000 rows, 150 columns

Splitting data into train and validation sets...
Train set: 8000 rows
Validation set: 2000 rows

Preparing features...
Number of features: 140

Training lightgbm model...

Evaluating on validation set...

Validation Metrics:
----------------------------------------
RMSE: 0.012345
MSE: 0.000152
MAE: 0.009876
R2: 0.234567
CORRELATION: 0.485432
----------------------------------------

Model saved to models/model_lightgbm.pkl

Training completed!
```

### Saved Files
- **Model File**: `models/model_{model_type}.pkl`
  - Contains the trained model, feature columns, and preprocessing information
  - Example: `models/model_lightgbm.pkl`, `models/model_xgboost.pkl`

## 2. Prediction Output (`predict.py`)

When you run `python3 predict.py`, the following outputs are generated:

### Console Output
- **Data Loading**: Confirmation of loaded test data
- **Feature Preparation**: Feature processing status
- **Model Loading**: Confirmation of loaded model
- **Prediction Statistics**:
  - Number of predictions
  - Mean prediction value
  - Standard deviation
  - Minimum value
  - Maximum value

### Example Console Output:
```
Loading test data...
Loaded test data: 500 rows, 145 columns
Preparing features...
Loading model from models/model_lightgbm.pkl...
Making predictions...

Predictions saved to submission.csv
Number of predictions: 500
Prediction statistics:
  Mean: 0.001234
  Std: 0.012345
  Min: -0.045678
  Max: 0.056789
```

### Saved Files
- **Submission CSV**: `submission.csv` (or custom path specified with `--output`)
  - Format:
    ```csv
    date_id,forward_returns
    1,0.001234
    2,-0.002345
    3,0.003456
    ...
    ```
  - Contains:
    - `date_id`: Trading day identifier
    - `forward_returns`: Predicted daily returns for S&P 500

---

## 3. Output File Locations

### Default Locations:
- **Trained Models**: `models/model_{model_type}.pkl`
- **Predictions**: `submission.csv` (in project root)

### Customizable:
- Model directory: `--model-dir` flag in `train.py`
- Output file: `--output` flag in `predict.py`

## 4. Output File Formats

### Model File (`.pkl`)
- Format: Python pickle file (joblib format)
- Contains:
  - Trained model object
  - Feature column names
  - Preprocessing scaler (if applicable)
  - Model type information

### Submission File (`.csv`)
- Format: CSV with headers
- Columns:
  1. `date_id` (integer): Trading day identifier
  2. `forward_returns` (float): Predicted returns
- No index column
- Ready for Kaggle submission

## 5. Evaluation Metrics Explained

### RMSE (Root Mean Squared Error)
- Lower is better
- Measures average magnitude of prediction errors
- Penalizes larger errors more heavily

### MSE (Mean Squared Error)
- Lower is better
- Average of squared differences between predicted and actual values

### MAE (Mean Absolute Error)
- Lower is better
- Average absolute difference between predicted and actual values
- Less sensitive to outliers than RMSE

### R² (R-squared)
- Higher is better (range: -∞ to 1)
- Proportion of variance in target explained by model
- 1.0 = perfect predictions, 0.0 = model performs as well as predicting the mean

### Correlation
- Higher is better (range: -1 to 1)
- Linear relationship strength between predictions and actual values
- 1.0 = perfect positive correlation, -1.0 = perfect negative correlation

## 6. Example Workflow Outputs

### Complete Training and Prediction Workflow:

```bash
# Step 1: Train model
python3 train.py --model-type lightgbm
# Output: models/model_lightgbm.pkl + console metrics

# Step 2: Make predictions
python3 predict.py --model-path models/model_lightgbm.pkl
# Output: submission.csv + console statistics
```

### Files Generated:
1. `models/model_lightgbm.pkl` - Trained model
2. `submission.csv` - Predictions for submission
