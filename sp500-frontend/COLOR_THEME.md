# Black & Green Color Theme

## 🎨 Color Scheme

The website now features an attractive **black and green** color scheme:

### Primary Colors
- **Primary Green**: `#10b981` (Emerald Green)
- **Primary Light**: `#34d399` (Light Green)
- **Primary Dark**: `#059669` (Dark Green)
- **Secondary**: `#065f46` (Deep Forest Green)

### Background
- **Gradient**: Black to dark green gradient
- **Cards**: White with green accents
- **Glassmorphism**: Subtle blur effects

### Accents
- **Green Glow**: Subtle glow effects on interactive elements
- **Shadows**: Green-tinted shadows
- **Borders**: Green borders on active elements

## ✨ Features

### Visual Effects
- ✅ Green glow on buttons and interactive elements
- ✅ Smooth green gradients
- ✅ Green-tinted shadows
- ✅ Animated green status indicators
- ✅ Green text shadows on headings

### Interactive Elements
- ✅ Green hover effects
- ✅ Green active states
- ✅ Green focus rings
- ✅ Green loading spinners

### Typography
- ✅ Green gradient text on headings
- ✅ Green accents on important text
- ✅ Green version badges

## 🎯 Design Philosophy

The black and green theme creates a:
- **Modern**: Sleek, contemporary look
- **Tech-forward**: Matrix/cyber aesthetic
- **Professional**: Clean and polished
- **Eye-catching**: Green glows draw attention
- **Accessible**: Good contrast ratios

## 🔄 What Changed

- Background: Purple gradient → Black to green gradient
- Primary color: Purple → Green
- Buttons: Purple → Green with glow
- Links: Purple → Green
- Status indicators: Green with pulse animation
- Shadows: Purple tint → Green tint
- Borders: Purple → Green

The theme maintains all animations and modern design while using the black and green color scheme!
